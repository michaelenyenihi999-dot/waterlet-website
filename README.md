## How to Deploy (Free Hosting)

### Option 1: Netlify (Easiest – Recommended)
1. Go to https://www.netlify.com and sign up (free).
2. Drag and drop the entire `waterlet-website` folder onto the Netlify dashboard.
3. Your site will go live instantly with a free URL like `something.netlify.app`.
4. (Optional) Connect your own domain `waterletglobalempire.com` later in Netlify settings.

### Option 2: Vercel
1. Go to https://vercel.com and sign up with GitHub (or email).
2. Import the folder or push to a GitHub repo and connect it.
3. Deploy – free URL provided.

### Option 3: GitHub Pages
1. Create a free GitHub account.
2. Create a new repository (e.g. `waterlet-website`).
3. Upload all files from this folder.
4. Go to Settings → Pages → Source: Deploy from branch `main` / root.
5. Site will be live at `https://yourusername.github.io/waterlet-website`.

### Option 4: Cloudflare Pages
1. Sign up at https://pages.cloudflare.com
2. Upload the folder or connect a GitHub repo.
3. Free and very fast.
